[WARNING]
.Reference implementations are not production software
====
The reference implementations in this repository show how a pattern is built, and nothing more.
They deliberately omit security: there is no authentication, no authorisation, no transport security, no secrets handling and no hardening of the runtime.
Do not use them as-is in production.

This applies to the software the reference implementations produce, not to this repository: the repository itself, its build and its pipelines are secured, as link:SECURITY.md[SECURITY.md →] describes.
====

This repository holds the design patterns published by Arc-E-Tect.
Every pattern has a document that describes it, and a reference implementation that shows it working, test-first and verified in the build.

[#development]
== Development

Install the repository's Git hooks once after cloning:

[source,console]
----
./scripts/setup-hooks.sh
----

Each project's README says how to build, test and run it.
The Java builds need Java 25; each project brings its own Gradle wrapper.
The `api` library needs Node.js instead, as its README says.

link:docs/decision-log.adoc[The decision log →] records every decision taken for this repository, with its reason.
