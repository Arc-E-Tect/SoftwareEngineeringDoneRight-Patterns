== Adding a pattern

A new pattern gets a folder `patterns/<pattern-name>/` with:

* `README.adoc`, which introduces the pattern and links to its document and its reference implementation;
* `<pattern-name>-pattern.adoc`, the pattern document;
* one folder per project of its reference implementation, each a standalone Gradle build with its own `README.adoc`.

Its API specification, if it has one, is a bundle target of the shared specification library at the root of the repository.
The new pattern is added to the table above and to the root README's index.
