The code reviews of this repository: the prompt each review runs, the report each review writes, and what came of each finding.
The review index ties them together, so that it is clear which prompt produced which report, and which pull requests a finding led to.

== Running a review

. Use link:code-review-prompt.adoc[the review prompt →], at its current version.
. Set `PROMPT_FILE` to `docs/code-review/code-review-prompt.adoc`, `BASELINE_REPORT` to the latest report in <<runs,Reviews §>>, and `OUTPUT_REPORT` to `docs/code-review/code-review-follow-up-<date>.adoc`.
. The review records the prompt's version and blob ID in its report, adds its row to <<runs,Reviews §>>, and fills in the _Verified in_ column of <<findings,Findings §>>.
. A change to the prompt raises its `:prompt-version:` and adds a row to its history, in a commit of its own, so that every report names the exact text it was produced with.

A blob ID identifies a file's exact content, whatever the merge strategy; `git log --find-object=<blob ID>` finds the commits that hold it.
